# 项目功能介绍

Smart Testing Platform 是一套面向 UI 自动化测试与测试分析的智能化平台。它把“自然语言描述测试意图”转换为“可执行的自动化流程”，再把执行过程中的界面行为、接口调用和链路信息串联起来，帮助测试人员从“会点页面”升级为“能看穿系统”。

## 核心价值

### 1. 自然语言驱动 UI 自动化

平台基于多模态模型和执行智能体，将测试人员用自然语言描述的操作意图直接转化为 UI 自动化步骤。测试人员不再需要手工编写和维护传统的 UI 自动化脚本，就可以快速创建、执行和复用测试用例。

与依赖 `id/class/xpath/css` 等传统定位方式不同，平台采用视觉定位与页面理解能力来识别目标元素，更贴近真实用户视角。这种方式可以显著降低因页面结构调整、元素层级变化、属性重命名等带来的脚本失效问题，让 UI 自动化更稳定，也更适合频繁迭代的业务系统。

### 2. 智能链路采集与根因分析

平台在执行 UI 自动化的同时，结合智能链路染色与分布式链路追踪系统，自动采集接口调用、trace 信息、调用拓扑和日志上下文，形成完整的链路视图。

这意味着 UI 自动化不再只停留在“页面是否点通”的表层验证，而是可以进一步看到请求在后端系统中的流转过程、定位异常发生在哪一层、分析问题是来自接口、服务还是下游依赖。测试人员能够透过界面观察后端架构运行状态，并更快完成问题定位和根因分析。

## 主要功能

- 项目管理：按项目隔离测试资产、执行配置和权限。
- 用户与权限：支持 JWT 登录、用户管理、角色控制和项目级授权。
- 测试用例管理：支持 CRUD、自然语言生成、YAML 编辑、执行与复用。
- 测试计划管理：支持将多个用例组织为计划，按顺序或批量执行。
- 执行管理：支持单条执行、批量执行、进度推送、取消执行和状态同步。
- 报告中心：展示执行结果、历史报告、合并报告、链路追踪和日志分析。
- AI 配置：支持配置模型、Base URL、API Key、模型名称和浏览器模式。
- 故障模拟与链路分析：结合 SkyWalking、Kafka 和执行期采集数据进行诊断。

## 技术架构

```text
前端 Vue 3 + Vite + Element Plus
    |
    |  HTTP / WebSocket / SSE
    v
API Gateway (Spring Cloud Gateway, 8080)
    |
    +--> Platform Service (Spring Boot, 8081)
    |       - 项目 / 用户 / 用例 / 计划 / 报告
    |       - NLP 脚本生成
    |       - 根因分析
    |       - 报告存储与查询
    |
    +--> Eureka Server (8761)
    |
    +--> Execute Service (Node.js, 默认 3001)
            - Midscene + Playwright 执行引擎
            - 进度推送
            - 报告生成
            - 链路采集
```

## 典型工作流

1. 用户在前端创建或选择测试用例。
2. 通过自然语言描述测试意图，生成 YAML 脚本，或直接编辑 YAML。
3. 将用例加入测试计划，或直接执行单条用例。
4. 执行引擎拉起浏览器，并按步骤完成 UI 自动化。
5. 执行过程中持续回传进度、链路和状态信息。
6. 生成报告后进入报告中心，可查看执行结果、调用链和根因分析结论。

## 适用场景

- 希望快速批量构建 UI 自动化用例的测试团队。
- 希望降低脚本维护成本、提升稳定性的业务系统团队。
- 希望把 UI 验证、链路观测和故障定位打通的质量平台建设团队。
