# Spec: 测试计划管理

## Requirement: 测试计划 CRUD 及用例关联管理

### Description
用户可以将一个项目下的测试用例组织成可复用的测试计划，支持按项目分组查看、创建计划、管理计划内的用例。

### Scenarios

**Scenario 1: 从用例管理页创建测试计划**
- Given 用户已登录，进入用例管理页
- When 用户筛选项目后勾选多个用例，点击"保存为测试计划"
- Then 弹出对话框要求输入计划名称
- When 用户输入名称后点击确认
- Then 测试计划创建成功
- And 该计划包含之前勾选的用例
- And 提示"保存成功"

**Scenario 2: 查看测试计划列表**
- Given 用户有权限的项目下有多个测试计划
- When 用户进入测试计划页
- Then 按项目分组展示所有计划
- And 每个计划显示名称和用例数量

**Scenario 3: 向计划添加用例**
- Given 存在一个测试计划（属于项目 A）
- When 用户在计划管理中点击"添加用例"
- Then 弹出选择框，仅展示项目 A 下的用例
- When 用户勾选用例后确认
- Then 这些用例被添加到计划中

**Scenario 4: 从计划移除用例**
- Given 测试计划中包含用例 X
- When 用户点击用例 X 的"移除"按钮
- Then 用例 X 从计划中移除
- And test_plan_cases 表中该关联记录被删除
- And 用例 X 本身未被删除

### Acceptance Criteria
1. 测试计划必须归属于一个项目，不可跨项目
2. 创建计划时至少需要指定名称和项目
3. 从用例管理页创建时自动关联已选中用例
4. 向计划添加用例时只能选择同一项目下的用例
5. 删除计划时级联删除关联关系
6. 权限规则：general 用户只能看到自己有权限的项目的计划
7. 一个项目下可以有多个测试计划

### Error Handling
- 计划名称不能为空，长度不超过128字符
- 添加已存在的关联时自动跳过（uk_plan_case 唯一约束）
- 项目不存在时返回 404
- 用例不属于该项目时返回 400
