## 用户自测清单（运行环境）

| # | 步骤 | 预期 |
|---|---|---|
| A1 | 详情页"登录方式"行点"编辑" | 弹窗打开，下拉预选当前绑定（含缓存状态标签） |
| A2 | 选已有登录方式 → 改账号/密码 → "保存并应用" | 保存成功；登录方式列表中该方式缓存状态变"未缓存"；基本信息行账号同步 |
| A3 | 选"免登录" → "确认换绑" | 基本信息行变"免登录"标签；执行时不再走登录阶段 |
| A4 | 选"➕ 新建登录方式" → 填类型/网址/账号/密码/补充步骤 → "保存并绑定" | 新方式出现在项目登录方式列表，当前用例绑定到它 |
| A5 | 选中当前绑定的登录方式 → "删除该登录方式" → 确认 | 当前用例先解绑，登录方式被删除 |
| A6 | 删除仍被同项目其他用例绑定的登录方式 | 后端拒绝（400 "该登录方式已被测试用例引用，无法删除"），前端 toast 展示 |
| A7 | 修改账号后执行用例 | 登录缓存失效（uncached），执行机重新登录并以新账号登录 |
