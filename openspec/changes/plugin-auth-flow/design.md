## 3. 数据存储设计

### localStorage 键值

| Key | 值 | 用途 |
|-----|-----|------|
| `midscene_platform_url` | `http://localhost:8080` | 中台地址（已存在，保留） |
| `midscene_export_form` | `{projectId, testUrl}` | 导出表单持久化 |
| `midscene_project_id` | `"abc123"` | 当前选中的项目 ID |
| `midscene_project_name` | `"项目A"` | 当前选中的项目名称 |
| `midscene_auth_token` | `"eyJhbG..."` | **新增**：JWT Token，持久化存储 |
| `midscene_auth_username` | `"admin"` | **新增**：当前用户名，用于工具栏显示 |
| `midscene_project_list` | `[{id, name}]` | 项目列表缓存 |

### 内存变量

| 变量 | 类型 | 用途 |
|------|------|------|
| `_authToken` | `string` | JWT Token，从 localStorage 恢复 |
| `_currentUser` | `object` | 当前登录用户信息 `{id, username, role}` |
| `_state` | `string` | 状态机：unauthenticated / project_select / ready |

## 4. API 调用流

### 4.0 启动验证

```
GET /api/platform/auth/me
Header: Authorization: Bearer <token>
Response 200: { id, username, role, ... }
Response 401: token 过期/无效 → 清除 localStorage → 弹出登录
```

### 4.1 登录流程

```
POST /api/platform/auth/login
Body: { username, password }
Response 200: { token, user: { id, username, role } }
Response 401: { error: "用户名或密码错误" }
→ 成功后 token + username 存入 localStorage
```

### 4.2 获取项目列表

```
GET /api/platform/projects?size=100
Header: Authorization: Bearer <token>
Response 200: { total, items: [{ id, name, ... }] }
```

### 4.3 创建项目

```
POST /api/platform/projects
Header: Authorization: Bearer <token>
Body: { name: "新项目名" }
Response 201: { id, name, ... }
```

### 4.4 导出用例（简化后，无变化）

```
POST /api/platform/cases
Header: Authorization: Bearer <token>
Body: { projectId, name, nlp }
```

## 5. 关键设计决策

### 5.1 Token 存储持久化

**决策：存 localStorage（v2 更新）**

- ✅ 关闭插件后重新打开，无需重新登录
- ✅ 启动时通过 `GET /auth/me` 验证 token 有效性
- ✅ Token 过期时自动清除并弹出登录
- ✅ 提供登出按钮，用户可主动清除
- ⚠️ 密码从不存储，只存 token + username

### 5.2 项目名存 localStorage

**决策：存 localStorage**

- ✅ 用户下次打开插件后，项目选择弹窗默认选中上次项目
- ✅ 导出弹窗也默认显示上次项目
- ✅ 敏感度低，不涉及密码

### 5.3 获取当前标签页 URL

**决策：每次点击"导出全量用例步骤"时实时获取（v2 更新）**

- ✅ 用户在操作过程中切换页面后，导出时自动获取当前页 URL
- ✅ 打开插件时默认填入初始页面 URL
- ✅ 用户可在导出弹窗中手动修改
- ✅ 关闭再打开插件 → 新会话 → 获取新 URL

```js
// 每次打开导出弹窗时实时获取
function refreshCurrentUrl(callback) {
  chrome.tabs.query({ active: true, currentWindow: true }, (tabs) => {
    var url = (tabs && tabs[0] && tabs[0].url && tabs[0].url.indexOf('chrome://') !== 0)
      ? tabs[0].url : '';
    callback(url);
  });
}

### 5.4 登录覆盖层的 UI 策略

- **自己渲染 HTML 元素**（而非修改 React 应用），避免与 Midscene React 应用冲突
- 覆盖在 `#root` 之上，使用 `position: absolute; z-index: 9999`
- 登录成功后 `display: none`，露出底层 AI 聊天界面
- 保留顶部 `#midscene-toolbar` 可见，保持品牌一致性

## 6. 风险与边界

| 风险 | 缓解措施 |
|------|----------|
| 中台不可达 | 登录前检测，不可达时友好提示 |
| Token 过期 | 启动时 GET /auth/me 验证 + 导出 401 时重新登录 |
| 用户无项目权限 | 项目列表为空时，引导用户创建新项目 |
| 标签页切换后导出 | 每次导出时实时获取当前标签页 URL |
| Chrome Extension API 限制 | `chrome.tabs.query` 在 side panel 中可用 |
| Token 泄露风险 | Token 存 localStorage，密码不存储；提供登出按钮 |
