# Proposal: 插件启动认证 & 导出流程简化

## 背景 (Why)

当前 Midscene.js 1.52 浏览器插件的"导出全量用例步骤"弹窗中，每次导出都需要用户手动输入**项目名称、账号、密码**：

1. **重复输入** — 用户每次导出测试用例都要输入账号密码，体验差
2. **无权限校验** — 插件启动时无登录流程，任何人打开插件都能操作
3. **项目无选择** — 用户只能盲打项目名，不知道已有哪些项目
4. **网址单调** — 测试网址需要手动输入，不能自动获取当前标签页 URL
5. **提示冗余** — "用例名称" placeholder 附带"不保存到本地"说明

## 目标 (What)

将**登录认证和项目选择**从"导出弹窗"前置到"插件启动"，实现：

| 改进项 | 当前 | 目标 |
|--------|------|------|
| 登录时机 | 每次导出时输入 | 插件打开时一次性输入 |
| 项目选择 | 手动输入项目名 | 下拉选择已有项目，支持新建 |
| 测试网址 | 每次手动输入 | 自动获取当前标签页 URL，可修改 |
| 用例名称 | placeholder 含冗余说明 | 简化为"请输入用例名称" |
| 导出弹窗 | 含账号/密码/项目名 | 移除账号密码，项目改为下拉 |

## 范围 (Scope)

### In Scope
- 插件侧边面板新增启动认证 UI（登录 + 项目选择覆盖层）
- 与中台后端 API 对接（`/auth/login`、`/projects` 列表、`/projects` 创建）
- 导出弹窗简化（移除账号/密码字段、项目名改为下拉）
- 自动获取当前活动标签页网址填充测试网址
- localStorage 持久化项目选择、平台地址
- token 内存存储（不存 localStorage，保证安全性）

### Out of Scope
- 后端 API 改造（已有接口完全满足需求）
- 插件 popup 弹窗改造
- Side Panel React 主应用内的 AI 配置 UI 改造
- 多标签页同时操作支持

## 影响 (Impact)

- **修改文件**：`Midscene.js 1.52/index.html`（新增 HTML）、`Midscene.js 1.52/scripts/export-test-case.js`（重写认证逻辑）
- **新增文件**：`Midscene.js 1.52/scripts/auth.js`（认证模块）
- **插件更新**：修改后需重新 zip → 放到 `frontend/public/plugin/midscene-extension.zip`
- **兼容性**：不影响已有 Midscene AI 聊天功能，仅在导出流程前后增加认证步骤
